# Environment variables

**Purpose:** provide the complete environment-name index. **Audience:** operators. **Mode:** reference.

ADO and PR: `SYSTEM_ACCESSTOKEN`, `ADO_AUTH_TOKEN`, `ADO_MCP_AUTH_TOKEN`, `ADO_API_KEY`, `ADO_ORG`, `ADO_PROJECT`, `ADO_REPO_ID`, `PR_ID`, `PR_URL`, `SOURCE_BRANCH`, `TARGET_BRANCH`. HTTP retries: `ADO_RETRY_ATTEMPTS` (default `3`), `ADO_RETRY_BASE_DELAY` (seconds, default `1`), `ADO_RETRY_CAP_DELAY` (seconds, default `30`), and `ADO_RETRY_BUDGET_SECS` (default `90`). Retries apply to safe GET transport/transient failures; POST/PUT retry only transport failures.

Review: `REVIEW_LANGUAGE`, `PI_MODEL`, `PI_THINKING` (default `medium`; Pi reasoning effort), `MAX_DIFF_BYTES`, `CHUNK_TRIGGER_DIFF_BYTES`, `DISABLE_CHUNK_REVIEW`, `PI_TIMEOUT_SECS`, `COMMIT_CONTEXT_MAX` (default `50`; commit subjects supplied as intent evidence), `ANCHOR_POLICY` (default `downgrade`; `drop` removes invalid diff anchors and `off` disables validation), `DRY_RUN`, `INCLUDE_WORK_ITEMS`, `INCLUDE_EXISTING_COMMENTS`, `VERIFY_FINDINGS`, `FORCE_REVIEW`, `FORCE_FULL_REVIEW`, `REVIEW_TARGET_BRANCHES`, `REPLY_COMMENTS` (default enabled; set to `0` to disable automatic in-thread replies).

Paths and runs: `WORKSPACE`, `CLONE_ROOT`, `REVIEW_PROMPT_PATH`, `INTENT_PROMPT_PATH`, `CONTEXT_PLAN_PROMPT_PATH`, `CONTEXT_DIGEST_PROMPT_PATH`, `VERIFY_PROMPT_PATH`, `SEVERITY_PROMPT_PATH`, `REVIEW_STANDARDS_PATH`, `REVIEW_ARTIFACT_DIR`, `REVIEW_ARTIFACT_ROOT`, `REVIEW_RUN_ID`, `AC_COVERAGE_PROMPT_PATH`, `FAST_REVIEW_PROMPT_PATH`, `CHUNK_SYNTHESIS_PROMPT_PATH`, `COMMENT_REPLY_PROMPT_PATH`, `COMMENT_TEMPLATE_PATH`.

Posting and context: `POST_MIN_SEVERITY`, `DROP_LOW_CONFIDENCE`, `REQUIRE_CONTEXT_FOR`, `MAX_FINDINGS`, `VOTE_WAITING_ON`, `FAIL_ON`, `CONTEXT_FILE_MAX_LINES`, `CONTEXT_SEARCH_MAX_MATCHES`, `COLLECT_CONTEXT_WORKERS`, `AC_COVERAGE_LLM`, `AC_COVERAGE_LLM_MAX_ACS`.

Engine and session: `REASONING_ENGINE`, `FAST_REVIEW`, `DEBUG_INTERMEDIATES` (default `0`; retain multi-stage fragment documents under `raw/` for debugging), `PI_SESSION_ID`, `PI_SESSION_ENABLED`, `PI_SESSION_CLEAR`, `ESCALATION_REVIEW_ENABLED` (default `0`; run a focused second pass over escalation-hinted files), `ESCALATION_REVIEW_MODEL` (optional model for that pass; defaults to `PI_MODEL`), `REVIEW_LOG_LEVEL` (default `INFO`; standard-library log level for stderr and `run.log`). Pi retry: `PI_RETRY_ATTEMPTS` (default `2`; total attempts per primary reasoning call, `1` disables retry), `PI_RETRY_BASE_DELAY` (seconds, default `5`; first backoff, doubles per attempt), and `PI_RETRY_CAP_DELAY` (seconds, default `60`; maximum backoff). Retries apply to a non-zero Pi exit (e.g. a transient "terminated" session failure), never to timeouts or empty output.

CRG enrichment: `CRG_ENABLED` (default `0`; set to `1` to activate the Tree-sitter context-enrichment stage). `CRG_CACHE_DIR` optionally overrides the persistent graph-cache root. `CRG_CONTEXT_MAX_BYTES` (default `8192`) caps the foundation context. Wave-two flags `GRAPH_API_DIFF`, `GRAPH_FLOWS`, and `GRAPH_ARCH` are independent and default off. API base snapshots use `<CRG_CACHE_DIR>/<repo-slug>/base-snapshots/<base-sha>.json`; `GRAPH_CONTEXT_MAX_BYTES` (default `12288`) caps their deterministic prompt sections. Each enabled feature writes an independent `ok` or `degraded` section status and none can fail the review.

Values are parsed by `Config` unless documented otherwise; boolean values accept `1`, `true`, `yes`, or `on` (case-insensitive).
